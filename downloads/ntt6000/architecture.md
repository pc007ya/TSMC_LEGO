# 臺中國家歌劇院・建築對照

站在惠來路的噴水廣場看歌劇院，先找入口上方的兩面玻璃。由地面往上看，玻璃從寬闊的入口收窄，再向兩旁鼓起。視線往右移，第三處同樣的曲線包著一個向內凹的白色空間。站到街角，才能看清它的深度。兩個玻璃開口下方各有一道細長水平雨棚。[伊東豊雄、大矩聯合建築師的作品實景](https://www.twarchitect.org.tw/works/臺中國家歌劇院/) · [Arup 工程團隊的正面與斜角照片](https://www.arup.com/en-us/projects/the-national-taichung-theater/)

## 從廣場、側面到屋頂

| 視角 | 實景中可以辨認的地方 |
| --- | --- |
| 從噴水廣場看入口 | 灰白曲面之間嵌著大片玻璃。細直窗格與外緣曲線並置，沿著前方的淺水池可以看見立面全貌。[主創建築師發表的空拍圖](https://www.twarchitect.org.tw/web2015/wp-content/uploads/2017/02/201703a1-1.jpg) |
| 從側面看戶外劇場 | 草地上有半圓形階梯座席，下方的舞臺連到室內小劇場。從座席回望，牆面的細小孔洞和大片玻璃有截然不同的尺度。[場館介紹與戶外劇場照片](https://www.npac-ntt.org/about/architecture/venue#d) |
| 從六樓看空中花園 | 淺色步道穿過綠地，在底部外張的白色火山形量體之間轉彎。從高處看，花園還與深色、方整的屋頂量體並存。[空中花園實景](https://www.npac-ntt.org/about/architecture/venue#f) · [建築師空拍圖](https://www.twarchitect.org.tw/web2015/wp-content/uploads/2017/02/201703a1-1.jpg) |

打開「雙劇場剖視」，可看到紅色大劇院和藍色中劇院各自的舞臺與階梯座席。原建築由 58 面曲牆、29 個洞窟組成。模型以有限的磚格重建這些空間的連接，觀眾席排數、玻璃窗格與屋頂植栽皆作縮編。[兩座劇場的席區照片](https://www.npac-ntt.org/about/architecture/venue) · [歌劇院建築設計](https://www.npac-ntt.org/about/architecture/design)

## 兩枚貼紙怎麼分辨

入口上方的實景館名是同排的中、英文淺金色字。模型將字樣印在深色底上，配合雨棚上方的黑色長磚。另一枚位於模型展示牌，採用場館的紅色圖形和上下兩行的雙語館名。北士設計以「壺中居」曲面和五線譜發展這枚紅色識別。[入口字牌現場照片](https://upssmile.com/64985/national-taichung-theater) · [場館正式識別](https://www.npac-ntt.org/dispPageBox/npac-ntt/images/logo-footer.svg) · [識別設計團隊說明](https://www.pace.com.tw/collection-identity.html?id=6)
